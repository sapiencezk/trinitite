# IEC 61499 — pointer

The IEC 61499 kernel, its compiler, the full node and the plan live in
[1499kernel](https://github.com/sapiencezk/1499kernel); this tree is its
`trinitite` submodule.

This tree is the lite node's host only: it boots the kernel jam 1499kernel
builds and runs it under fixed caps (see [HOST-CONTRACT.md](HOST-CONTRACT.md)).
It has no execution control, function block network or IEC types in C; those
are the kernel's. Do not implement them here.
