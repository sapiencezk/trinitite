## Substrate contracts (this repo)

Trinitite provides the host only (no IEC ECC / FB semantics):

- Shrine: free event nouns → `[effects [kernel causes]]`
- Effect dispatch (`DO-FX`), event queue, MMIO, net stubs, cold store, hot-swap, trace
- **Multi-arm timers:** `%tset [id period]` / `%tcan id` → fire `[%ei id %TICK 0]` (slip on overrun)
- Forth: `TPOLL` `TACLR` `TACT?` `TNXT@` `TDUE` (tests / manual poll; kernel loop polls automatically)

Do not implement IEC Table 1 or CFB networks in this tree.

### Host status (see HOST-INDUSTRIAL.md)

- **WP1 done:** empty queue **idles** with `uart_rx_ready` + `tarm_poll` + soft WDT.  
- **WP2 done:** slam op budget (`BUDGET!` / default 1e6 in kernel loop) + mid-eval wall poll; abort keeps tarms, emits `%timeout`.  
- **WP3 done:** C jets for `%eq` bit ops tree axes `%lent/%flop/%weld` (+ existing arithmetic). KERNEL uses C `hot_state`; SKA may still prefer Forth shadows for arithmetic names.
